# Function_assignment


This repository contains a collection of JavaScript practice questions and their solutions. The assignment focuses on functions, conditions, loops, string methods, Math methods, arrow functions, and basic problem-solving.

## 📌 About the Project

This project includes **20 JavaScript questions** covering different programming concepts. A total of **23 functions** are implemented because some questions require more than one function.
